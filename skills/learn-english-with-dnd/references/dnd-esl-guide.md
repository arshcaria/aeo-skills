# D&D ESL Teaching Guide

Use this reference selectively for dense fantasy prose, dialect, rules terminology, or review design. Do not force these categories onto a simple line.

## Diagnose why a line feels difficult

Classify the main obstacle before explaining it:

| Obstacle | Typical signal | Teaching move |
|---|---|---|
| Archaic register | `thou`, `thee`, `thy`, `hast`, `doth`, `ere`, `lest` | Convert to modern English, then explain tone |
| Literary syntax | inversion, long fronted phrases, delayed subject | Restore ordinary word order |
| Ellipsis | missing subject/verb or compressed reply | Supply omitted words in brackets |
| Idiom/phrasal verb | literal words do not yield the intended meaning | Teach the whole chunk and one neutral example |
| Pragmatic implication | threat, refusal, sarcasm, hedging | State what the speaker is doing socially |
| Rare sense | familiar word used unusually | Contrast common and local senses |
| Fantasy coinage/name | capitalized or invented form | Separate sound/image from established meaning |
| Rules term | ordinary word with defined mechanics | Label `普通英语` versus `游戏术语` |
| Dialect | nonstandard spelling, contractions, grammar | Give standard English without mocking the speaker |

## Modernize pseudo-medieval English

Use these mappings as orientation, not as a claim about every context:

Call forms such as `thou`, `thee`, and `doth` **archaic**, **pseudo-medieval**, or **Early Modern English-style** in Chinese explanation (`古体/仿中古/早期现代英语式`). Do not casually label them `Old English/古英语`; Old English is a much earlier language stage.

| Form | Modern core | Note |
|---|---|---|
| `thou / thee` | `you` | subject / object |
| `thy / thine` | `your / yours` | `thine` can also precede a vowel in older usage |
| `art / hast / dost` | `are / have / do` | second-person singular verb forms |
| `doth` | `does` | often elevated or deliberately old-fashioned |
| `ere` | `before` | literary/archaic |
| `lest` | `so that ... not / for fear that` | usually carries prevention or fear |
| `hence / thence / whence` | `from here / from there / from where` | verify the direction in context |
| `wherefore` | `why` | not normally `where` |
| `would that ...` | `I wish that ...` | expresses an unreal or difficult wish |

Always provide a full modern-English rewrite; word substitutions alone may leave the syntax opaque.

## Explain high-value fantasy and D&D language

First decide whether the word is ordinary English, literary fantasy language, or a defined rules term.

- **Ordinary word with a game sense:** `party`, `class`, `save`, `turn`, `level`, `spell`, `feat`, `check`, `rest`.
- **Often rules-specific:** `Armor Class`, `saving throw`, `hit points`, `damage roll`, `spell slot`, `alignment`, `proficiency`, `caster level`.
- **Fantasy vocabulary that may remain ordinary English:** `ward`, `bane`, `boon`, `oath`, `heir`, `kin`, `realm`, `blight`, `smite`, `vanquish`, `forsake`.

Do not import mechanics from a different D&D edition. Explain the wording on screen and add edition-specific detail only when the game/ruleset is established and the detail is needed.

## Explain tone without inventing plot

Use calibrated labels such as:

- `礼貌但疏远`
- `正式、带权威感`
- `表面客气，实际拒绝`
- `试探而非承诺`
- `威胁，但没有说明会采取什么行动`
- `带讽刺；讽刺目标仅按当前措辞判断`

Avoid labels that smuggle in future knowledge, such as “he is lying,” “this is a trap,” or “choose this to save X,” unless the supplied text itself establishes that claim.

## Convert analysis into learning

Prefer this sequence:

1. Give the natural meaning.
2. Rewrite in plain modern English.
3. Extract 2–4 chunks.
4. Explain one meaningful grammar/tone feature.
5. Ask one retrieval question using a non-plot example.

Good practice prompts are brief:

- Fill one missing chunk.
- Choose between two near-synonyms and explain the tone.
- Paraphrase one line in modern English.
- Reuse a phrase in an everyday context.

Do not turn every screenshot into homework. If the user is moving quickly through dialogue, save items for a later review when asked.

## Preserve uncertainty

Use explicit confidence when text is unclear:

- `确定读到：...`
- `这一处可能是 X，也可能是 Y；两者会改变句意。`
- `右侧被截断，因此只能解释前半句。`

Never reconstruct missing text from remembered game dialogue; doing so risks both error and spoilers.
