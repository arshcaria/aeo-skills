# 数据字段说明

## 持仓明细表字段

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| 序号 | int | 计算生成 | 按持仓市值降序重新排列 |
| 股票代码 | str | API | 如 `603808`、`300305` |
| 股票名称 | str | API | 如 `歌力思` |
| 占净值比例(%) | float | API 原始值 | 基金报告中的"占基金资产净值比例" |
| 持仓市值占比(%) | float | **计算生成** | `个股持仓市值 / 该期股票持仓总市值 × 100` |
| 持股数(万股) | float | API 原始值 | |
| 持仓市值(万元) | float | API 原始值 | |

## 两个"比例"的区别

### 占净值比例（API 原始值）

- 分母 = 基金资产净值（NAV）
- 含义：该股票占基金总规模的百分比
- 问题：部分微量持仓（如 IPO 新股获配）该值为 0.00%，但实际有市值
- 精度：API 返回值为 2 位小数百分比

### 持仓市值占比（计算值）

- 分母 = 该报告期所有股票持仓市值合计
- 含义：该股票占股票投资组合的百分比
- 优势：消除了债券/现金等其他资产的稀释效应，真实反映个股在股票组合中的权重
- 精度：3 位小数

### 转换关系

```
持仓市值占比(%) = 占净值比例(%) / 股票占比(%) × 100
```

其中 `股票占比(%) = 股票持仓市值合计 / 基金总规模 × 100`

## 概览表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 报告期 | str | `YYYY-MM-DD`，如 `2025-12-31` |
| 报告类型 | str | `年报` 或 `中报/半年报` |
| 股票数 | int | 该期持仓股票总数 |
| 基金总规模(亿元) | float | 来自 gmbd API 的"期末净资产" |
| 股票持仓(亿元) | float | 所有股票持仓市值合计，万元 → 亿元 |
| 股票占比(%) | float | `股票持仓 / 基金总规模 × 100` |
| 其他资产(亿元) | float | `基金总规模 - 股票持仓` |
| 其他占比(%) | float | `其他资产 / 基金总规模 × 100` |
| 第一大重仓 | str | 按持仓市值排序的第一名股票名称 |
| 第一大占比(%)* | float | 占股票持仓比例（非占净值） |
| 前十大占比(%)* | float | 前十大持仓合计占股票持仓比例 |

## "其他资产"的含义

```
其他资产 = 基金总规模 - 股票持仓
```

其他资产包含但不限于：
- 债券（国债、企业债、可转债等）
- 银行存款
- 结算备付金
- 应收款项
- 其他投资

> 注意：该值为近似值，因基金总规模（gmbd）和股票持仓（jjcc）可能存在统计口径差异或四舍五入误差。

## 单位换算

| 原始单位 | 换算 | 目标单位 |
|---------|------|---------|
| 万元 | ÷ 10000 | 亿元 |
| % (2位小数) | 保留原值 | % |
| % (计算值) | 保留 3 位小数 | % |
